Dados simulados

Preenche o mapa com denúncias classificadas em Blumenau, cada uma com uma foto. Preencher de novo substitui o conjunto anterior. Limpar apaga só esses dados simulados. Denúncias recebidas pelo Telegram ou WhatsApp permanecem.

Com o modo demonstração ligado, a foto e a localização chegam pelo Telegram. A foto é salva na hora, aparece no mapa, e o worker classifica depois. O mapa mostra o ponto e a imagem enquanto a categoria chega.

run.py já inicia o worker de classificação. Para vê-lo num terminal separado, suba a API com LIMCITY_EMBED_WORKER=0 e rode python -m app.workers.classify_worker. As fotos ficam em data/report-images.
